# 电赛相关选题调研

查证日期：2026-10-13。主要从全国竞赛培训网站和上海赛区网站核对题目主题。

| 来源 | 核查内容 | 对项目的启发 |
|---|---|---|
| [2021 年 F 题：智能送药小车](https://www.nuedc-training.com.cn/index/news/details/new_id/259) | 发布条目和搜索摘要确认题名；正文页面请求未成功，未据此引用精确尺寸或限时 | 路口导航、目的地识别与返航任务 |
| [2025 年 K 题：自动避障小车](https://res.nuedc-training.com.cn/topic/2025/topic_130.html) | 题名、年份和“高职高专组”在发布页核实；图像附件请求失败 | 道路状态变化和停止/重新选择路径 |
| [2025 年上海赛区赛题发布](https://nuedc-sh.sjtu.edu.cn/post_detail.php?id=44) | 本科、高职高专赛题分开提供的官方入口 | 区分组别，避免将不同题目要求混用 |
| [2026 年上海赛区赛题发布](https://nuedc-sh.sjtu.edu.cn/post_detail.php?id=57) | 当年省级赛事列表含车载平衡滚球控制题 | 确认本项目为独立导航练习，并非“2026 国赛小车题完整解答” |

选题落在送药/寻迹/避障小车的共同导航部分。地图、障碍和风险数值由当前项目自行设计；没有把自建地图冒充官方赛道，也没有从网上复制获奖队程序。

本项目不声明某届整题达标。车体尺寸、指定器件、末端位置与朝向、速度、装卸提示和多车任务应在取得对应组别完整赛题后单独做映射与验收。
